# Мини-Ральф для финансовых задач (автономный цикл)

Идея: превратить разовую генерацию инвойса в **автономный цикл**, который сам проходит список работы до конца. Развитие того, что уже собрано 2026-07-15 — unattended-генерация инвойса без промптов (`gen_invoice.py` + `render_check.py`).

## Что такое Ральф

Техника Geoffrey Huntley для Claude Code. Его же формулировка: *«Ralph is a Bash loop»* — примитивный `while true`, который раз за разом скармливает агенту **один и тот же промпт-файл**, а агент итеративно доводит работу до готовности, сам себя проверяя, пока не закроет все пункты. Назван в честь Ralph Wiggum.

Смысловая разница с тем, что у нас есть сейчас:
- **Сейчас:** «сделай ОДИН инвойс без запросов» (unattended, один проход).
- **Ральф:** «крутись над СПИСКОМ, пока не закроешь все» (unattended + цикл).

## Конкретный сценарий под финансы

Цикл «новые PO → инвойсы»:

1. Найти новые PO у клиента (`…\[Клиент]\90-Finance\20-PO\`), на которые ещё нет инвойса в `30-INV\`.
2. Для каждого: прочитать PO (встроенный Read) → собрать `spec.json` → `gen_invoice.py` → `render_check.py`.
3. Проверить результат (вид + содержание, `RESULT: PASS`), положить в `finance-docs-to-sort\`.
4. Повторять, пока необработанные PO есть. Когда список пуст — **выйти** и доложить сводку.

Каждый кусок уже готов и allowlisted — Ральф лишь оборачивает их в петлю с условием выхода.

## Обязательные предохранители

Наивный `while true` жжёт токены и может зациклиться. Нужны:

- **Лимит итераций** (напр. ≤ N проходов за запуск) — жёсткий стоп.
- **Детекция выхода** — «нет новых PO» / «все PASS» = завершить, а не крутиться.
- **Бюджет токенов/времени** — верхний предел на запуск.
- **Громко падать, а не тихо врать** — если PO не читается или `render_check` = FAIL, остановиться с ошибкой на этом элементе, не «протолкнуть» кривой инвойс. (Тот же принцип, что в [[local-cloud-split-via-git]].)
- **Идемпотентность** — не плодить дубли: элемент считается сделанным, если инвойс уже есть (по номеру PO). Пропускать готовое.

## Как запускать

- Локально проще всего через уже имеющийся скилл **`/loop`** (запуск промпта/команды по кругу с самопейсингом) — это по духу тот же Ральф.
- Требование: весь путь **без permission-промптов** (иначе цикл встанет на первом же запросе). Инвойс-поток это уже выполняет; для любого нового шага — заранее в allowlist (см. [[permissions-unattended]]).
- Готовые реализации-референсы: `snarktank/ralph`, `frankbria/ralph-claude-code` (с детекцией выхода), официальный плагин-пример `ralph-wiggum` в `anthropics/claude-code`.

## Статус

Идея, не реализовано. Кирпичи готовы (unattended-инвойс), не хватает только петли + условия выхода + предохранителей. Начинать — с одного клиента и жёсткого лимита итераций, вручную наблюдая первый прогон.
