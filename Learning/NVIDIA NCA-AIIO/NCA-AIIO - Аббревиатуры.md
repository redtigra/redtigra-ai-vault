## GPU, память и вычисления

CUDA::Compute Unified Device Architecture — платформа и модель программирования NVIDIA для параллельных вычислений на GPU.

HBM::High Bandwidth Memory — многослойная память с высокой пропускной способностью, размещённая рядом с GPU в одном корпусе (package).

FLOPS::Floating Point Operations Per Second — число операций с плавающей точкой в секунду; показатель вычислительной производительности. При сравнении учитывай точность и условия измерения.

FP32::32-bit Floating Point — представление числа с плавающей точкой в 32 битах; одинарная точность.

FP16::16-bit Floating Point — представление числа с плавающей точкой в 16 битах; половинная точность.

FP8::8-bit Floating Point — семейство 8-битных форматов с плавающей точкой; уменьшает объём данных, но ограничивает точность и диапазон.

FP4::4-bit Floating Point — семейство 4-битных форматов с плавающей точкой; очень компактное представление с низкой точностью.

PCIe::Peripheral Component Interconnect Express — последовательная шина подключения GPU, сетевых адаптеров и других устройств к системе.

SXM::Форм-фактор GPU-модуля NVIDIA, устанавливаемого на базовую плату (baseboard); используется в серверных системах с NVLink. Запоминай назначение обозначения.

MXM::Mobile PCI Express Module — компактный модульный форм-фактор графических адаптеров, первоначально для мобильных систем.

DPU::Data Processing Unit — процессор разгрузки инфраструктурных задач: сети, хранения и безопасности. Пример: NVIDIA BlueField.

MIG::Multi-Instance GPU — аппаратное разделение поддерживаемого GPU на изолированные экземпляры с выделенными вычислительными ресурсами и памятью.

vGPU::Virtual GPU — виртуальный GPU для виртуальной машины. NVIDIA vGPU поддерживает разделение по времени и варианты на основе MIG; это не только программное разделение.

NVL72::Обозначение стоечной системы с 72 GPU в одном NVLink-домене, например GB200 NVL72. Число 72 относится к GPU, а не к числу серверов.

## Сети и соединения

RDMA::Remote Direct Memory Access — прямой доступ к памяти другого узла по сети, в том числе чтение и запись, с обходом ОС в пути передачи данных и минимальным участием CPU.

RoCE::RDMA over Converged Ethernet — передача RDMA по Ethernet; RoCEv2 использует UDP/IP.

PFC::Priority Flow Control — управление потоком Ethernet по приоритетам: позволяет приостановить отдельный класс трафика при перегрузке.

ECN::Explicit Congestion Notification — явное уведомление о перегрузке через маркировку пакетов; помогает отправителю снизить скорость.

NDR::Обозначение поколения InfiniBand со скоростью до 400 Гбит/с на полный четырёхлинейный порт в одном направлении. Запоминай соответствие NDR → 400G.

XDR::Обозначение поколения InfiniBand со скоростью до 800 Гбит/с на полный четырёхлинейный порт в одном направлении. Запоминай соответствие XDR → 800G.

DAC::Direct Attach Copper — кабель прямого соединения с медными проводниками, обычно для коротких расстояний.

AOC::Active Optical Cable — активный оптический кабель со встроенными оптическими преобразователями на концах.

QSFP::Quad Small Form-factor Pluggable — семейство форм-факторов подключаемых трансиверов и кабельных модулей; Quad указывает на четыре электрических канала в базовом QSFP.

OSFP::Octal Small Form-factor Pluggable — форм-фактор подключаемых трансиверов и кабельных модулей с восемью электрическими каналами.

DDM::Digital Diagnostics Monitoring (также Digital Diagnostic Monitoring) — телеметрия трансивера: температура, напряжение, ток лазера, передаваемая и принимаемая оптическая мощность.

BER::Bit Error Rate — доля ошибочно принятых битов; метрика качества линии. Различай BER до и после FEC.

FEC::Forward Error Correction — прямая коррекция ошибок: избыточное кодирование позволяет приёмнику исправлять часть ошибок без повторной передачи.

## Эксплуатация и охлаждение

BMC::Baseboard Management Controller — контроллер внеполосного управления сервером: питание, датчики, удалённая консоль; работает независимо от основной ОС.

PUE::Power Usage Effectiveness — отношение общего энергопотребления дата-центра к энергопотреблению IT-оборудования за тот же период; безразмерная величина, идеал — 1.

WUE::Water Usage Effectiveness — расход воды относительно энергопотребления IT-оборудования; обычно выражается в литрах на кВт·ч.

CUE::Carbon Usage Effectiveness — выбросы парниковых газов, связанные с энергопотреблением дата-центра, относительно энергопотребления IT-оборудования; обычно кг CO₂-экв. на кВт·ч.

CDU::Coolant Distribution Unit — узел распределения и управления теплоносителем в системе жидкостного охлаждения; обычно включает насосы, теплообменник и контроль параметров.

CDM::Coolant Distribution Manifold — коллектор распределения и сбора теплоносителя, например между серверами в стойке.

DLC::Direct Liquid Cooling — прямое жидкостное охлаждение: тепло от компонентов передаётся теплоносителю, например через холодные пластины (cold plates).

DCGM::Data Center GPU Manager — набор инструментов NVIDIA для мониторинга, диагностики и управления GPU в дата-центре.

## Платформы и рабочие нагрузки

DGX::Семейство готовых AI-систем NVIDIA: в контексте дата-центра — AI-сервер от NVIDIA с GPU, CPU, памятью, сетью и программным стеком для обучения и инференса. Линейка также включает целые стойки и настольные системы.

HGX::Серверная GPU-платформа NVIDIA: базовая плата с GPU и высокоскоростными соединениями NVLink/NVSwitch, на основе которой сторонние производители собирают готовые AI-серверы.

BasePOD::NVIDIA DGX BasePOD — проверенная эталонная архитектура корпоративного AI-кластера: DGX-узлы, сеть, хранилище и ПО управления. Можно начать с нескольких узлов и масштабировать кластер.

SuperPOD::NVIDIA DGX SuperPOD — масштабируемая инфраструктура крупного AI-кластера по проверенной эталонной архитектуре NVIDIA: DGX-системы, сети, хранилище и управление. Строится из масштабируемых блоков (Scalable Units, SU); их размер зависит от поколения, поэтому «от 32 узлов» не универсальное правило.

NGC::NVIDIA GPU Cloud — платформа и каталог NVIDIA с GPU-оптимизированными контейнерами, моделями и другими ресурсами; включает реестр контейнеров.

NIM::NVIDIA Inference Microservices — оптимизированные микросервисы NVIDIA для развёртывания и выполнения инференса AI-моделей.

VDI::Virtual Desktop Infrastructure — инфраструктура виртуальных рабочих столов, размещённых на сервере и доступных удалённо.

HPC::High Performance Computing — высокопроизводительные вычисления, часто с параллельной обработкой на кластерах.

SDK::Software Development Kit — комплект средств разработки: библиотеки, инструменты, документация и примеры.

## Модели и методы AI

CNN::Convolutional Neural Network — свёрточная нейронная сеть; часто применяется для обработки изображений.

RNN::Recurrent Neural Network — рекуррентная нейронная сеть; обрабатывает последовательности, передавая скрытое состояние между шагами.

GAN::Generative Adversarial Network — генеративно-состязательная сеть: генератор и дискриминатор обучаются в состязании.

LSTM::Long Short-Term Memory — разновидность рекуррентной сети с ячейкой памяти и вентилями, позволяющая учитывать длительные зависимости.

GRU::Gated Recurrent Unit — рекуррентный блок с вентилями обновления и сброса, управляющими скрытым состоянием.

LLM::Large Language Model — большая языковая модель для обработки и генерации языка.

LMM::Large Multimodal Model — большая мультимодальная модель, работающая с несколькими типами данных, например текстом и изображениями.

RAG::Retrieval-Augmented Generation — генерация с дополнением найденной информацией: сначала поиск во внешних источниках, затем ответ модели с этим контекстом.

GNN::Graph Neural Network — графовая нейронная сеть, работающая с узлами графа, их связями и признаками.

MoE::Mixture of Experts — смесь экспертов: архитектура с несколькими экспертными блоками и маршрутизатором, выбирающим экспертов для входных данных.
