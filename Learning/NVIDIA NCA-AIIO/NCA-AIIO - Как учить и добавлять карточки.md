# NCA-AIIO — Как учить и добавлять карточки

Карточки: [[NCA-AIIO - Аббревиатуры]]. Одна заметка со всеми сокращениями, одна колода `nca-aiio`, тематические заголовки для навигации.

## Первый запуск

В этом хранилище вручную установлен **Spaced Repetition 1.15.4**, автор Stephen Mwangi (`st3v3nmw`). Файлы официального релиза загружены в `.obsidian/plugins/obsidian-spaced-repetition`, их SHA-256 проверены по данным GitHub. Плагин добавлен в список включённых, настройки записаны в `data.json`.

1. Если хранилище уже открыто в Obsidian, перезапусти приложение, чтобы оно подхватило плагин и настройки.
2. Открой заметку с аббревиатурами.
3. Нажми **Ctrl+P**, найди **Spaced Repetition: Review flashcards in this note** (в русском интерфейсе — команда повторения карточек текущей заметки).
4. Выбери колоду `nca-aiio`, если появится выбор. Вспомни расшифровку и смысл до открытия ответа, затем оцени ответ.

Запуск интерфейса Obsidian из этой задачи не проверялся. Если команды нет, открой **Настройки → Сторонние плагины / Community plugins** и включи Spaced Repetition; при включённом Restricted mode сначала разреши сторонние плагины.

Для другого устройства или хранилища: **Настройки → Сторонние плагины → Обзор / Browse → Spaced Repetition → Установить / Install → Включить / Enable**. Установку и настройки там нужно проверить отдельно: папка плагинов исключена из Git этого хранилища.

## Применённые настройки

| Параметр | Значение и смысл |
| --- | --- |
| Flashcard tags | `#flashcards`; тег заметки `#flashcards/nca-aiio` создаёт вложенную колоду |
| Convert folders to decks | Выключено: колода определяется тегом |
| Single-line separator | `::` — одна карточка, слева вопрос, справа ответ |
| Single-line reversed separator | `:::` — две карточки, в обоих направлениях |
| Algorithm | SM-2-OSR, исходный алгоритм плагина; для старта дополнительная настройка не нужна |
| Card order | DueFirstRandom: сначала назначенные повторения, затем новые; порядок случайный |
| Bury sibling cards | Включено: связанные обратные карточки откладываются до следующего дня |
| Show context | Включено: при повторении видны название заметки и тематический раздел |
| Scheduling data | В Markdown-заметке; служебный комментарий на той же строке, что и карточка |
| Панель повторения целых заметок при запуске | Выключена |

Синтаксис и организация колод описаны в [документации карточек](https://stephenmwangi.com/obsidian-spaced-repetition/flashcards/q-and-a-cards/) и [документации тегов](https://stephenmwangi.com/obsidian-spaced-repetition/flashcards/decks/). Точная схема настроек сверена с исходным кодом установленной версии 1.15.4.

## Добавить термин за несколько секунд

1. Открой [[NCA-AIIO - Аббревиатуры]] через **Ctrl+O**; для быстрого доступа можно добавить заметку в закладки Obsidian.
2. Перейди в конец (**Ctrl+End**) и допиши одну строку с пустой строкой перед ней:

```text
ABC::English Full Name — короткое объяснение по-русски.
```

3. Продолжай курс. Obsidian сохраняет заметку автоматически; при следующем запуске повторения плагин подхватит карточку. Импорт, отдельный файл, повторный тег и ручное назначение даты не нужны. Если окно повторения уже открыто, закрой и открой его после редактирования.

Саму карточку пиши обычным текстом заметки, **вне блока кода**. В примерах этой инструкции блоки кода нужны только для показа синтаксиса. Для одной карточки вопрос и ответ должны быть на одной физической строке; перенос по ширине окна редактора допустим.

Для термина, который нужно вспоминать в обе стороны, используй три двоеточия:

```text
ABC:::English Full Name — краткий смысл.
```

Это создаёт две карточки: сокращение → ответ и ответ → сокращение. Если термин уже есть, замени разделитель в существующей строке; не добавляй дубликат. В стартовом наборе используется только `::`, чтобы не удваивать объём повторений. После начала обучения меняй тип карточки осознанно: может измениться её расписание.

Для более длинного вопроса есть многострочный формат:

```text
Вопрос
?
Ответ, который может занимать несколько строк.
```

После такого ответа нужна пустая строка. `??` вместо `?` создаёт две карточки в противоположных направлениях.

## Почему одна заметка

Для коротких определений одна заметка упрощает добавление и поиск дублей. Заголовки делят материал на GPU, сети, эксплуатацию, платформы и модели. У каждой карточки собственное расписание, даже если все находятся в одном файле.

Отдельную заметку имеет смысл создавать, когда у термина появляется полноценный конспект: схема, примеры, ограничения. Из ответа карточки можно поставить ссылку на этот конспект. Если общий файл станет неудобен, раздели его по темам, оставив в каждой заметке тот же тег колоды. Переноси карточку вместе с её служебным комментарием, не копируй её повторно.

## Как повторять

Начни с 5–10 новых терминов в день и сначала проходи назначенные повторения. Это ориентир нагрузки, а не установленный программный лимит. Достаточно короткой ежедневной сессии; неизвестное слово сначала разбери по курсу.

Для выбранного SM-2-OSR: **Hard / Трудно** — забыл или существенно ошибся; **Good / Хорошо** — вспомнил; **Easy / Легко** — ответил уверенно и без усилий. Если вспомнил расшифровку, но не назначение, не ставь «Легко».

В обычные дни используй **Review**, где работает расписание. **Cram** подходит для дополнительного прогона всех карточек перед проверкой знаний.

Плагин дописывает комментарии вида `<!--SR:...-->`: это [данные расписания](https://stephenmwangi.com/obsidian-spaced-repetition/data-storage/). Не удаляй и не вводи их вручную. При добавлении термина создавай новую строку без чужого комментария. В режиме чтения комментарии скрыты.

## Уточнения к стартовому набору

Все исходные термины сохранены. FP32, FP16, FP8, FP4, NDR, XDR, QSFP, OSFP, WUE и CUE вынесены в самостоятельные карточки.

- HBM находится рядом с GPU в одном корпусе, а не внутри его вычислительного кристалла: [NVIDIA о H100 и HBM3](https://developer.nvidia.com/blog/?p=68661).
- MIG и vGPU не взаимоисключающие технологии: существует [MIG-backed vGPU](https://docs.nvidia.com/ai-enterprise/release-7/latest/infra-software/vgpu/features/mig-backed-vgpu.html).
- Для NDR/XDR запоминаем 400/800 **Гбит/с**, а не ГБ/с; это скорость полного порта в одном направлении: [NVIDIA DGX SuperPOD](https://docs.nvidia.com/dgx-superpod/reference-architecture/scalable-infrastructure-b300-xdr/latest/dgx-superpod-components.html).
- SXM оставлен как обозначение форм-фактора без придуманной расшифровки: [NVIDIA A100, SXM и PCIe](https://www.nvidia.com/content/dam/en-zz/Solutions/Data-Center/a100/pdf/nvidia-a100-datasheet-us-nvidia-1758950-r4-web.pdf).
- DDM встречается с вариантами Diagnostic и Diagnostics: [документация Nokia](https://documentation.nokia.com/sr/22-10/books/interface-configuration/digital-diagnostics-monitor.html).
- CDM — распределительный коллектор: [описание производителя Global Tek](https://www.globaltekww.com/en/manifold).
- NGC включает контейнеры, модели и другие ресурсы: [справочник каталога NVIDIA](https://docs.nvidia.com/ngc/latest/ngc-api-field-value-reference.html). NIM — микросервисы инференса: [обзор NVIDIA NIM](https://docs.api.nvidia.com/nim/docs/introduction).
- NVL72 — обозначение системы с 72 GPU в NVLink-домене: [NVIDIA GB200 NVL72](https://www.nvidia.com/en-us/data-center/gb200-nvl72/).

Основа набора — разобранные пользователем термины курса; это учебная колода, а не официальный перечень экзаменационных вопросов.
